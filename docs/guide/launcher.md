# The launcher

A quick tour of the launcher's pages. Use the bar at the top to move between them, or press **Ctrl+1** to **Ctrl+5**.

## Home

Your starting point.

- **Play**: starts the profile you played last. Open the switcher above it to pick another profile, or choose
  **More versions and ways to play**. On your very first visit Home offers two ready-made versions instead, plus
  **More versions** and **Browse modpacks**.
- **View crash** appears here if the last game crashed.
- **Profiles** and **Friends**: jump back into a recent profile, or see who's online.

The bar along the bottom always shows what will launch (the **launch target**), any downloads in progress, and a
**Play / Stop** button for the selected profile.

## Play

Three tabs: **Instances** (yours, with a dot when the Nether client is on), **Modpacks** and **Horizon**. The list
shows name, Minecraft version, loader and when you last played. From here you can:

- **New instance**: Quick (pick a version and play) or Manual (version, loader, Nether on / off, mods, resource packs).
  With no instances yet, Play shows these steps right away. See [Profiles](profiles.md).
- **Import**: bring in a modpack file or the profiles of another launcher.
- Open a profile to manage its mods, packs, worlds, screenshots and logs.

## Install Packs

Search modpacks on Modrinth, filter them by loader and category, sort them (by relevance while you search), and
install one as a new profile in one step.

## Host

Run a Minecraft server from one of your profiles (Vanilla or Fabric) and play on it with friends. Pick the profile at
the top, then **Set up server** (downloads the official server into the profile's `server` folder) and **Start
server**. The first start asks you to agree to Mojang's EULA; nothing is accepted for you.

- **Share with friends** shows the address to give them: your public address when your router opened the port
  (UPnP), otherwise your LAN address. They add it under **Multiplayer**, then **Direct Connect**. **Check from
  outside** tests whether the internet can reach it.
- **Console**: the server log, and a box for commands (up and down arrows go through earlier ones).
- **Players**: who's online (kick, op, whitelist), plus the whitelist and operator lists.
- **Settings**: port, message, max players, memory, difficulty, game mode, PvP, online mode, whitelist and
  automatic port opening. Changes save as you type and apply on the next start.
- **World**: copy one of the profile's singleplayer worlds in as the server world (the old one is set aside, not
  deleted), and make backups.

One server runs at a time. The bottom bar shows it while it runs, and closing the launcher stops it cleanly.

## Wardrobe

Your skins and capes, with a live 3D preview. See [Skins, capes and cosmetics](wardrobe.md).

## Friends

The **Friends** button in the top bar opens your friends list: who's online and what they play, requests, and blocked
players. See [Friends, parties and world invites](friends.md).

## Settings

| Section | What you can change |
|---|---|
| **Shared game settings** | Share keybinds, video, audio, chat and mod video settings (Sodium, Embeddium, OptiFine) between all your profiles, so you set them once. Each part can be turned on or off. **Import from Minecraft launcher** copies your existing settings in; **Open settings file** opens the shared file. |
| **Accounts** | Sign in, add accounts, switch the active one, sign out. |
| **Java** | The Java each Minecraft version uses. Usually leave this alone; you can pick a different Java for one profile on its Overview. |
| **Launcher** | Hardware acceleration, start with Windows, what the launcher does when a game starts, whether the close button quits or hides to the tray, reduced motion, interface sounds. |
| **Personalization** | Accent colour, text size, and Dark or Light theme. The theme also applies to the in-game menu. |
| **Storage & About** | Open your data folders, clear the download cache, check for updates, beta updates, and **Support** (open logs, **Copy system info** for bug reports). |
| **Privacy** | Turn capes and cosmetics in game and Discord status on or off, and see every online service the launcher uses. |

## Keyboard shortcuts

| Keys | Does |
|---|---|
| **Ctrl+K** | Search everything: pages, settings, profiles, worlds and mods |
| **Ctrl+1** to **Ctrl+5** | Go to a page |
| **Ctrl+,** | Settings |
| **Ctrl+N** | New instance |
| **Esc** | Close the open dialog |

## When something goes wrong

If Minecraft crashes, the launcher opens a crash page that explains what it found and how to fix it. See
[Troubleshooting](troubleshooting.md).
