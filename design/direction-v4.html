Minecraft-style font

All of these are SIL OFL, so we can bundle them in the launcher and the agent. Mojang's own font (Mojangles) can't be shipped. My pick: Pixelify Sans for titles, buttons and module names, with a clean sans for body text and numbers, because pixel fonts get hard to read at 11 to 13 px in long settings lists. Switch "Pixel font on" to Everything above to see the full River look.

Decisions for you

  • 1. Default theme. Obsidian (lifted dark grey, our identity) or Slate (River's blue-grey). Ice and OLED ship as options either way.
  • 2. Accent. Keep racing red as default with the picker (already in Settings), or default to something calmer.
  • 3. Font. Which pixel font, and pixel on headings only or everywhere.
  • 4. Retire "Pit Wall". This drops the slanted PLAY slab, zero-radius rule and top tab bar for a sidebar with 4-5px corners. The ghast logo stays.
  • 5. Order. In-game menu first (you see it most), then launcher shell, then each launcher screen.
