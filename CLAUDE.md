# Nether Client
Minecraft launcher + client in **Rust** (no Electron/webview). Palette: obsidian black, ice grey, racing red accent. Vault: `NC Obsidian Vault/` (keep tiny; decisions only; update, don't append).

**Always read first:** `NC Obsidian Vault/Index.md` and `NC Obsidian Vault/Rules.md`.

## Which note for which task
| Task | Read |
|---|---|
| UI, styling, layout, theming, animation | `Design.md` |
| What to build, scope, priorities | `Features.md` |
| Stack, crates, structure, client engine (`nether-agent`), auth, APIs | `Architecture.md` |
| What's next / status | `Todo.md` |

## Working rules
- Rule 1: Appearance is the only representation we get — polish every screen.
- Smallest complete change; no unrequested features.
- Don't read whole vault; open only the note for the task.
- After a design/stack decision, update the relevant note in 1–3 lines; tick Todo.
- Never overfill the vault; no prose, no logs.
