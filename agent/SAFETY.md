# Nether Client: module safety

Every module only shows what the game already gives you, or changes how things look. Zoom, Fullbright and Reach Display
are the ones some servers treat as an advantage; they are off by default (Reach) or only on while you use them (Zoom), so
check a server's rules before turning them on.

| Module | Notes |
|---|---|
| Zoom, Fullbright, Reach Display (default off) | can be an advantage on some servers |
| Crosshair, Own Nametag | looks only (the crosshair is a texture in the built-in resource pack) |
| Combo Counter (own clicks and own hurt flash only; default off), Item Counter (own inventory) | own data |
| FPS, CPS, Ping, Keystrokes, Stopwatch | own data |
| Coordinates, Compass, Waypoints (incl. death point), Speed, Day Counter, Clock, Session, Memory (coordinates hide themselves where the server hides F3 data) | own data |
| Potion Effects, Armor Status, Server Address | own data |
| Media Player, Lyrics | your PC's media session |
