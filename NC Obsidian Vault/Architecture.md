# Architecture
- **Launcher:** Rust workspace: `core` (instances, auth, download, java, host), `ui`, `app`.
- **Build prereqs (Windows):** rustup stable-msvc + VS Build Tools (C++ workload + Win SDK); without them rustc hits Git's `link.exe` ("extra operand"). JDK only to rebuild the agent.
- **UI: Slint (decided via prototype, `crates/app`).** Renders the Home screen near-identically to the mockup: gradients, SVG, sliding indicator, ember particles + ambient drift all in-Slint at runtime. Gaps: no backdrop blur (glass = translucent gradient), fonts must be embedded (Chakra Petch, Inter, JetBrains Mono still TODO; prototype used system font), no clip-path (chamfers via Path). iced stays as fallback if blur/shaders become essential.
- Async tokio + reqwest, hash-verified downloads. TOML + SQLite cache. Auth: MS OAuth → Xbox → MC, OS keyring.
## Client engine = `nether-agent` (Lunar-style injection, NOT a Fabric mod)
- Launcher adds `-javaagent:nether-agent.jar` to the JVM args → works on vanilla/Fabric/Forge/NeoForge/Quilt, any mod list. Loader-agnostic.
- **Hook below the game, not inside it:**
  - *Overlay:* hook the window swap (1.8.9 LWJGL2 `Display.update`; modern LWJGL3 `glfwSwapBuffers`) → draw HUD last, on top of the final frame. Save/restore full GL state. Immune to Sodium/Iris/DH since we never touch their code.
  - *Input:* chain the GLFW key/mouse callbacks (LWJGL2: poll hook). Keybinds, in-game menu, CPS.
  - *Game state:* read/write via runtime reflection using Mojang mappings (piston-meta) or native names on 26.x. No class patching.
- **Hook tiers:** A = swap/input/reflection only (default, safe). B = narrow ASM patch of a vanilla class, opt-in per module, never renderer classes (Sodium/Iris/DH/Embeddium areas banned). Every B hook gets a conflict audit + off switch.
- Module feasibility: Tier A: FPS/CPS/ping/coords/keystrokes/armor+potion HUD, crosshair overlay, toggle sprint (synth input), zoom (FOV option), fullbright (gamma), waypoints overlay, in-game menu. Tier B/later: freelook (camera yaw), hit color, replay, anything drawn inside the 3D scene.
- Version adapter layer: `GameAdapter` (state/mappings), `GlBackend` (GL compat 1.8.9 vs core profile 1.21+/26.x). Risk: Mojang's expected Vulkan move would break the GL hook → keep backend abstract (verify status).
- Agent is Java (Instrumentation + ASM, shaded/relocated to avoid classpath clashes); Rust↔agent config via layered TOML + local socket hot reload.
- Compliance: stay within server rules (Hypixel etc. allow Lunar-class features); no unfair-advantage modules by default.
## Versions
- 1.8.9: Java 8, LWJGL2, compat GL. 1.21.11: Java 21, last obfuscated, LWJGL3. 26.x (26.3 out 2026-09-15): unobfuscated, Java 25; mods built for ≤1.21.11 don't run — irrelevant to the agent, but reflection targets change.
